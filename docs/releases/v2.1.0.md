# Zelda3 2.1.0

Brazilian Portuguese support, remappable save/load state shortcuts and improved
Android autosaving. The app is displayed as **Zelda3** on Android.

## Changes

- Recognizes the supported spyblack/Denim PT-BR ROM by checksum. First-time
  setup needs only the translated ROM, including support for a copier header.
- Imports translated dialogue, fonts, in-game UI graphics and text tables:
  file menus, player names, inventory, HUD, game-over animation and ending/credits,
  following the original translation. The original ROM retains English.
- Localizes Android second-screen tabs, settings, maps, button mapping and
  save-state controls, with accented pixel lettering and corrected glyph rendering.
- Adds a Quick State card alongside the four existing manual slots. Settings,
  the card and controller shortcuts share the same quick-save file.
- Adds remappable Save/Load commands, defaulting to R2/L2 when available, with
  clearing, conflict handling, one action per press and brief result feedback.
- Saves automatically before Android suspends the game when entering the
  background, if enabled. Writes preserve the previous save on failure; startup
  uses checked loading. Abrupt termination can still prevent the latest save.

## Installation and existing saves

Download **zelda3-android-2.1.0.apk** from this release's Assets and install it.
It includes armeabi-v7a, arm64-v8a, x86 and x86_64 libraries.

This fork now uses its own permanent release signing key. Android cannot update
an existing debug or upstream installation signed by a different key. **Before
uninstalling anything, back up the complete app files folder to your computer:**

`Android/data/com.dishii.zelda3/files/`

It includes `saves/` (in-game progress, automatic, quick and manual states),
thumbnails, `zelda3.ini`, extracted assets and any additional content. Confirm
the backup is readable before removing the old installation. Install this APK,
then restore those files. On Android versions that restrict this folder, use
ADB over USB if available; do not uninstall until the backup has succeeded.

Existing PT-BR imports from before the in-game UI update need a one-time asset
reimport: after backing up, remove only `zelda3_assets.dat`, reopen the app and
select the supported translated ROM. Retain `saves/` and `zelda3.ini`. Imports
already made with the translated in-game UI do not need this step.

Future releases of this fork will reuse the same release key. The application ID
remains `com.dishii.zelda3`, so it occupies the same installation slot as upstream.

## Validation

Automated tests cover ROM import, UI package validation, graphics, save-state
compatibility, second-screen rendering, remapping and autosave lifecycle events.
The signed release APK is checked for identity/version, signature, four ABIs,
ZIP integrity and absence of ROMs or private credentials. SHA-256 is provided
in the attached checksum file.

The preceding debug build's PT-BR dialogue, game UI and corrected second screen
were tested on a device. **Installation and testing of this signed release on a
device remain pending confirmation.**

The app requires your own ROM; no ROM or extracted game asset container is included.
